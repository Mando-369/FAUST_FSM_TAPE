//############### jahysteresis.lib ##################
// Jiles-Atherton Magnetic Hysteresis Library
//
// A FAUST library implementing the Jiles-Atherton model of ferromagnetic
// hysteresis - a physically-based mathematical description relating
// magnetization (M) to applied field (H). Combined with a phase-locked bias
// oscillator for analog tape emulation applications.
//
// Full-physics implementation with runtime-adjustable parameters.
// Single mode: K60 Ultra (72 substeps, 3 integer cycles).
// CPU cost: ~2%.
//
// For the LUT-optimized multi-mode version (<1% CPU), see `jahysteresis_lite.lib`.
//
// * Physics Constants
// * JA Core Functions
// * Streaming Hysteresis
// * FSM Channel Processing
//
// It should be used using the `jah` environment:
//
// ```
// jah = library("jahysteresis.lib");
// process = jah.fsm_channel_ui;
// ```
//
// #### References
//
// * Jiles, D.C. and Atherton, D.L. (1986) "Theory of ferromagnetic hysteresis"
// * Walters, S.J. "Full Spectrum Magnetization" (phase-locked bias oscillator)
// * <https://github.com/Mando-369/FAUST_FSM_TAPE>
//
//##################################################

//================= Physics Constants ===============
// Default Jiles-Atherton model parameters.
// Ms = saturation magnetization, a = domain density,
// k = pinning (coercivity), c = reversibility, alpha = interdomain coupling.
//===================================================

//================= JA Core Functions ===============
// Core Jiles-Atherton physics implementation.
// Full computation for all substeps (no LUT).
//===================================================

//================= Streaming Hysteresis ===============
// Phase-locked bias oscillator with full JA computation.
// K60 Ultra mode: 3 cycles x 24 substeps = 72 total.
//======================================================

//================= FSM Channel Processing ===============
// Full Spectrum Magnetization channel with gain staging, drive, and mix.
//========================================================
